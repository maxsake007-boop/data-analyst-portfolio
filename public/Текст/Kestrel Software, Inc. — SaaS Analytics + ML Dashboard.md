## Kestrel Software, Inc. — SaaS Analytics + ML Dashboard

### Тип

Power BI дашборд

### Проблема бизнеса

Kestrel Software — B2B SaaS компания (Denver, Colorado), разработчик инструмента для управления проектами и командной работой, с двумя основными сегментами клиентов: SMB (self-serve) и Mid Market. Бизнес быстро рос, но у руководства не было ясности, откуда берётся общий показатель Net Revenue Retention и какой из сегментов реально тянет метрику вниз. Дашборд также должен был показать, как предсказания модели оттока клиентов могут быть встроены в повседневную работу команды Customer Success.

### Что сделано

- Данные для проекта сгенерированы синтетически с помощью ИИ (Python-скрипт) для симуляции реалистичных SaaS-метрик.
- ML-часть дашборда реализована через синтетические данные: вероятности оттока (churn probability), risk tier и факторы риска сгенерированы как правдоподобный output модели, без фактического обучения модели в рамках этого проекта. Задача была — научиться визуализировать и интегрировать ML-предсказания в BI-инструмент для конечного пользователя, а не в построении самой модели.
- Спроектирована звёздная схема: 3 фактовые таблицы (MRR по месяцам, продуктовые события, ML-скоры по риску оттока) и 4 таблицы измерений (аккаунты, даты, тарифные планы, Customer Success менеджеры).
- Данные подключены из нескольких источников: Google BigQuery (MRR, аккаунты, даты) и PostgreSQL (события, ML-скоры, планы, CSM).
- Построена модель данных в Power BI Desktop, написан набор DAX-мер (ARR, MRR, NRR, GRR, churn rate и другие).
- Собрано 5 страниц/представлений: welcome-страница, обзор для руководства, здоровье клиентской базы, churn intelligence на основе ML, drill-through по конкретному аккаунту (Customer 360°).
- Настроена навигация через bookmarks, единый тёмно-синий дизайн.

### Ключевые фичи Power BI

- **Waterfall / bar-разбивка MRR** по типам движения (New / Expansion / Churned)
- **Scatter chart** — Health Map аккаунтов (seat utilization vs интеграции, размер = MRR) и Churn Probability vs MRR
- **Визуализация ML-выхода** — risk tier, вероятность оттока, ключевые факторы риска по каждому аккаунту
- **Drill-through** — переход со страниц Customer Health и Churn Intelligence на полный профиль аккаунта (Customer 360°)
- **Field Parameters**, dynamic titles, YoY reference labels, conditional formatting (индикация высокого риска оттока)
- Единая Measures table для всех DAX-мер

### Стек

Power BI Desktop, DAX, Power Query (M), Google BigQuery, PostgreSQL, Figma (дизайн фона)

### Ключевые результаты / инсайты

- ARR — **$12.11M**, Current MRR — **$1.01M**, Blended NRR — **100.41%**
- NRR заметно различается по сегментам: **Mid Market — 99.5%**, **SMB — 93.26%**
- Logo Churn Rate у SMB (**79.41%**) значительно выше, чем у Mid Market (**16.92%**)
- GRR стабильно держится в диапазоне **97.3-98.1%** по кварталам
- Под риском оттока (High risk tier) — **153 аккаунта**
- Главный фактор риска у High-risk аккаунтов — **низкая утилизация seats** (68 аккаунтов), далее — малое количество интеграций
- Mid Market аккаунты в среднем подключают больше интеграций (**4.0** против **1.7** у SMB)
