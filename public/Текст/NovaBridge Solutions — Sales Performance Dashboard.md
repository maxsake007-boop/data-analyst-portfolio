## NovaBridge Solutions — Sales Performance Dashboard

### Тип

Power BI дашборд

### Проблема бизнеса

NovaBridge Solutions — B2B дистрибьютор коммерческого оборудования и офисных решений (Даллас, Техас) с командой из 10 менеджеров продаж, покрывающих всю территорию США. У VP of Sales не было единой картины: где именно теряются сделки в воронке продаж, какие менеджеры реально приносят результат, а какие только выглядят загруженными, и какие регионы стагнируют на фоне общего роста компании. Дашборд должен был показать это в разрезе воронки, команды и географии.

### Что сделано

- Данные для проекта сгенерированы синтетически с помощью ИИ (Python-скрипт) для симуляции реалистичного B2B sales-процесса.
- Спроектирована звёздная схема: 2 фактовые таблицы (сделки, активности по сделкам) и 6 таблиц измерений (аккаунты, стадии сделки, менеджеры, регионы, продукты, даты).
- Данные подключены из нескольких источников: Salesforce (сделки, аккаунты, стадии), Google Sheets (менеджеры, регионы, продукты), PostgreSQL (активности, календарь дат).
- Построена модель данных в Power BI Desktop, написан набор DAX-мер (revenue, win rate, avg deal size, pipeline coverage и другие).
- Собрано 6 страниц/представлений: welcome-страница, обзор для руководства, лидерборд команды, детализация по менеджеру (drill-through), воронка продаж, региональная карта.
- Настроена навигация через bookmarks, единый дизайн с кастомным фоном.

### Ключевые фичи Power BI

- **Photo-карточки менеджеров** с drill-through по клику на фото — переход на детальную страницу менеджера
- **Decomposition Tree** — разбивка выручки менеджера по региону и категории продукта
- **Scatter chart** — сопоставление активности и win rate по менеджерам, помогает выявить "занятых, но неэффективных"
- **Azure Maps** — визуализация выручки по регионам на карте США
- **Small multiples** — мини-тренды выручки по каждому менеджеру и по каждому региону
- **Funnel-style** визуализация конверсии сделок по стадиям воронки (Prospecting → Closed Won/Lost)
- **Gauge chart** — прогресс выполнения годового плана по выручке
- Conditional formatting, dynamic titles, YoY, drill-through → Manager Detail, единая Measures table

### Стек

Power BI Desktop, DAX, Power Query (M), Salesforce, Google Sheets, PostgreSQL, Azure Maps, Figma (дизайн фона)

### Ключевые результаты / инсайты

- Общая выручка: **$58.82M**, Win Rate — **53.3%**, средний размер сделки — **$147K**, Pipeline Value — **$175M**
- Топ-3 менеджера по выручке: **James Mitchell** ($10.39M), **Marcus Johnson** ($9.75M), **Sarah Chen** ($9.70M) — заметный отрыв от остальной команды
- Явная связь между размером скидки и результатом: у топ-менеджера (James Mitchell) средняя скидка **8%**, у части менеджеров с более скромными результатами скидка доходит до **26%**
- В воронке продаж самая заметная точка потерь — переход от **Proposal (69.13%)** к **Negotiation (34.38%)**: почти половина сделок теряется на этом шаге
- Итоговый Win Rate по воронке — **54.8%**, при этом в течение года заметен резкий провал в отдельные месяцы (до 30%)
- Pipeline Coverage — **2.97x**, средний цикл сделки — **~61 день**
- Лидер по выручке среди регионов — **Mountain West**, при этом **West Coast** — самый слабый по объёму продаж регион
