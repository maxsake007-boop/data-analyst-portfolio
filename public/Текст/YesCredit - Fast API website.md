## Тип
ML-модель + веб-приложение (дипломная работа, PROWEB)

## Проблема бизнеса
Вымышленная компания YesCredit предоставляет банкам и частным лицам услугу по определению кредитного рейтинга: пользователь вводит свои данные и за секунды узнаёт вероятность одобрения кредита. По результату компания связывается с клиентом и помогает подобрать подходящий банк.

## Что сделано
Датасет с публичного Kaggle (ссылка не сохранилась), содержит поля вроде дохода, суммы и срока кредита, кредитного рейтинга (CIBIL), стоимости активов, образования и занятости заявителя. Проект состоит из двух этапов:

- Обучение модели. Данные обработаны и подготовлены (кодирование категориальных признаков через LabelEncoder), обучены и сравнены две модели классификации: логистическая регрессия и случайный лес. По точности (accuracy) на тестовой выборке случайный лес показал заметно лучший результат (0.98 против 0.90 у логистической регрессии), поэтому выбран для финального приложения.
- Веб-приложение. Создан сайт на HTML/CSS (первый опыт вёрстки), с формой ввода данных заявителя (доход, сумма и срок кредита, кредитный рейтинг, стоимость активов, образование, занятость). Бэкенд на FastAPI обрабатывает запрос, прогоняет данные через обученную модель и возвращает результат: статус одобрения и вероятность в процентах. Интерфейс включает анимации (плавное появление элементов, зацикленная анимация иллюстрации, интерактивные карточки и поля ввода).

## Стек
Python (numpy, pandas, matplotlib, seaborn, scikit-learn), FastAPI, HTML, CSS

## Ключевые результаты / инсайты
- Сравнение двух моделей классификации: логистическая регрессия (accuracy 0.90) и случайный лес (accuracy 0.98)
- Для продакшн-версии выбран RandomForestClassifier как более точная модель на этом датасете
- Приложение запускалось локально, деплой на внешний хостинг не производился
