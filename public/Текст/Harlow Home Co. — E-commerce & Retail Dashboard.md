## Harlow Home Co. — E-commerce & Retail Dashboard

### Тип

Power BI дашборд

### Проблема бизнеса

Harlow Home Co. — D2C интернет-магазин товаров для дома (Остин, Техас) с выручкой около $5M в год. Бизнес быстро рос за счёт расширения ассортимента и рекламы, но владелец не понимал: какие категории товаров реально прибыльны, какие клиенты возвращаются, и почему первый квартал каждый год проседает по продажам. Дашборд должен был дать ответы на эти вопросы в одном месте.

### Что сделано

- Данные для проекта сгенерированы синтетически с помощью ИИ (Python-скрипт) для симуляции реалистичного бизнес-сценария D2C ритейлера — такой подход позволил тренироваться на разных бизнес-доменах без ожидания реальных клиентских данных.
- Спроектирована звёздная схема данных: 2 фактовые таблицы (заказы, возвраты) и 5 таблиц измерений (клиенты, товары, даты, каналы продаж, промоакции).
- Данные подключены из нескольких источников: CSV, Google Sheets и Pipedrive (через веб-коннектор с M-кодом / Coupler.io).
- Построена модель данных в Power BI Desktop, написан набор DAX-мер (выручка, маржа, AOV, discount rate, repeat rate, LTV и другие).
- Собрано 6 страниц отчёта: welcome-страница, обзор продаж, анализ товаров, анализ клиентов, региональные продажи, промоакции и скидки.
- Настроена навигация между страницами через bookmarks, единый дизайн (кастомный фон в Figma).

### Стек

Power BI Desktop, DAX, Power Query (M), CSV, Google Sheets, Pipedrive, Azure Maps, Figma (дизайн фона)

### Ключевые результаты / инсайты

- Общая выручка за период: **$4.4M**, 14K заказов, средний чек **$315**
- Gross Profit Margin: **15.43%**
- Топ-категория по выручке — **Kitchen** ($1.14M), но по марже лидирует **Decor** (24.1%)
- Категория **Lighting** показывает отрицательную маржу — быстро растущее направление продаж оказалось убыточным
- Return Rate сильно различается по категориям: **Furniture — 16.7%** возвратов против **3.5%** у Textiles
- **Texas и California** дают 53% всей выручки — сильная географическая концентрация
- Repeat Rate — **9%**, но именно повторные клиенты формируют основную часть выручки (сегмент Returning — $3M из $4.4M)
- Discount Rate — **15.8%**, почти 80% заказов оформляются со скидкой
