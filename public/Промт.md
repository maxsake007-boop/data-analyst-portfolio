Создай интерактивный премиальный сайт-портфолио для Data Analyst (Аналитик данных / BI-разработчик).

ВЕСЬ САЙТ ДОЛЖЕН БЫТЬ ВЫПОЛНЕН В СТРОГО ОПРЕДЕЛЕННОЙ ЭСТЕТИКЕ (Apple Liquid Glass Minimalist Light Mode) С ИНТЕРАКТИВНЫМ ФОНОМ.

### 1. Визуальный стиль и дизайн-система:
- Общая тема: Чистый, кристальный светлый минимализм (Apple Premium). Фон — мягкий бело-серый (#ffffff и bg-zinc-50/50).
- Фоновый интерактивный холст (Interactive Canvas Background):
  - Полноэкранный canvas с сеткой деликатных микро-точек (dot grid, шаг ~34px, размер 1.5px, цвет rgba(15, 23, 42, 0.28)).
  - Магнитный эффект курсора: при наведении мыши точки плавно отталкиваются по радиусу (физика push/deflection), увеличиваются в масштабе и становятся более контрастными (до 0.65-0.95 opacity).
  - Эффект ряби от клика (Shockwave ripples): при клике по экрану расходится затухающая волна, смещающая точки сетки.
  - Под холстом — 3 мягкие органические градиентные сферы с размытием blur(100px) (radial-gradient из оттенков slate/zinc), создающие свет и объем для преломления в стекле.
- Эффект жидкого стекла (Liquid Glass / Glassmorphism):
  - Карточки и кнопки: background: rgba(255, 255, 255, 0.2), backdrop-filter: blur(16px) saturate(180%), граница 1px solid rgba(255, 255, 255, 0.45).
  - Световой внутренний блик: inset 0 1.5px 2px 0 rgba(255, 255, 255, 0.9).
  - Мягкая рассеянная тень: box-shadow: 0 20px 45px -15px rgba(0, 0, 0, 0.08).
- Типографика:
  - Cormorant Garamond / Playfair Display: курсивные утонченные заголовки («Data & Analytics Portfolio», «Selected Dashboards», «Business Impact»).
  - Inter: чистый, легко читаемый текст описания задач и бизнес-результатов.
  - JetBrains Mono: метрики, формулы, теги стека (SQL, Python, Power BI, Tableau, ClickHouse, dbt, Pandas), номера кейсов (01 / 05) и даты.

### 2. Структура и компоновка сайта:
- Single-Screen / Compact Responsive Viewport (сайт спроектирован так, чтобы вписываться в один экран без лишней портянки скролла на десктопах и планшетах, с плавной адаптивностью под мобильные):
  - Верхняя панель (Navbar): логотип/имя аналитика, статус занятости (пульсирующий зеленый бейдж "Open to opportunities"), стеклянные кнопки с иконками: Telegram, GitHub, LinkedIn / HH, Скачать резюме (CV).
  - Главная область из двух крыльев (2-Column Split Layout):
    1. ЛЕВОЕ КРЫЛО: Интерактивная 3D-галерея / Vertical Coverflow или интерактивный переключатель дашбордов. Каждый слайд — это превью интерактивного дашборда с реалистичной графикой, переключением по клику/колесу мыши и возможностью открыть интерактивное демо.
    2. ПРАВОЕ КРЫЛО: Презентационная карточка активного проекта из жидкого стекла (Liquid Glass Card):
       - Номер кейса: `01 / 05`
       - Название проекта (например: «E-commerce Unit Economics & Retention Dashboard», «B2B Sales Funnel & Cohort Analysis», «Product Metrics & A/B Test Engine»)
       - Категория: Power BI / Python ETL / PostgreSQL
       - Кнопка "Открыть интерактивный дашборд" (внешняя ссылка с эффектом свечения)
       - Ключевые выводы и метрики в виде стеклянных бейджей с галочками:
         * Рост конверсии воронки: +18.4%
         * Автоматизация отчетности: ускорение с 4 часов до 2 минут
         * Оцифровка Churn Rate и LTV по когортам
       - Блок «Бизнес-ценность (Business Impact)»: как этот дашборд помог топ-менеджменту или стейкхолдерам принимать решения на основе данных.
       - Стек технологий проекта: SQL, Power BI, DAX, Python, Superset, Airflow.
  - Нижний колонтитул (Footer): Минималистичный копирайт в моноширинном стиле.

### 3. Набор данных (Примеры проектов Data Analyst в коде):
1. **Executive Sales & Unit Economics Dashboard (Power BI / DAX)**: Комплексный дашборд юнит-экономики, CAC, LTV, ROMI, динамика выручки и маржинальности по каналам.
2. **Customer Cohort & RFM Segmentation (Python, ClickHouse, Tableau)**: Анализ оттока (Churn), когортный анализ повторных покупок, сегментация клиентской базы по RFM-модели.
3. **Automated ETL Pipeline & Product Analytics (PostgreSQL, dbt, Metabase)**: Автоматизированный пайплайн сбора продуктовых логов, мониторинг ключевых воронок и метрик онбординга.
4. **A/B Testing Framework & Experiment Dashboard (Python, Scipy, Streamlit)**: Оценка статистической значимости экспериментов, расчет Sample Size, визуализация p-value и доверительных интервалов.

### 4. Технические требования:
- React + TypeScript + Tailwind CSS
- Иконки: `lucide-react` (BarChart3, TrendingUp, Database, PieChart, ExternalLink, Terminal, CheckCircle2 и т.д.)
- Плавные микро-анимации при смене активного проекта (Fade/Slide transition).
- Наличие файла с подробным описанием структуры данных проектов (`src/data/projects.ts`), чтобы можно было легко менять тексты, ссылки и скриншоты.
